Ställ in fotoöverföring via Pi

Med Pi kan gäster spara färdiga foton direkt till sina telefoner via fotobåsens Wi-Fi. Gästnätet behöver inte internet. Ägaren ställer in stationen, parkopplingen och gäståtkomsten.

Fotoöverföring via Pi är byggd och installerad på vår teststation. Den är fortfarande avstängd i TestFlight. Innan den kan släppas behöver vi testa med en iPad och gästens telefon på Pi-wifi. En ägarnedladdning följer efter det godkännandet.

  1. Det här behövs

    Ägaren behöver en Raspberry Pi 3 med Debian Bookworm eller Trixie som stöds och ett operativsystem som är avsett för fotobåset. Skrivare är valfri.

  2. Förbered Pi

    Välj uttryckligen photos-v2 i installationsprogrammet på den befintliga Pi-enheten. Stationens konfiguration bevaras; det är ingen SD-kortsklon. Den första tekniska SSH-konfigurationen beskrivs separat i teknikerguiden.

  3. Parkoppla stationen

    Öppna Konfiguration → Enheter → Utskriftsstation på iPad och ange stationens privata parkopplingskod. Fotoöverföring via Pi finns separat under Konfiguration → Fotoöverföring via Pi. Dela inte koden med gäster.

  4. Aktivera evenemanget

    Slå på Fotohämtning via QR för evenemanget och välj Pi-server under Fotoöverföring. Gäster ser Wi-Fi-uppgifterna endast om ägaren uttryckligen tillåter gäståtkomst.

  5. Spara ett foto och avsluta evenemanget

    Gäster ansluter till Pi-Wi-Fi (internet behövs inte), skannar den andra QR-koden för fotot och trycker på Spara. När evenemanget är slut låser ägaren upp operatörsdelen så att appen kan återkalla Pi-kopior. Om Pi är offline ligger borttagningen kvar tills den återansluter. Foton som redan sparats på telefoner kan inte återkallas.

Nätverk och integritet

  • Överföring från iPad till Pi använder pinnad TLS; gästers lokala hämtning använder HTTP på Pi-Wi-Fi. Internet behövs inte.
  • En iPad med mobilanslutning kan fortfarande ha internet via mobilnätet när den är ansluten till Pi-Wi-Fi. Kontrollera på den faktiska enheten.
  • En direkt Ethernetkabel mellan Pi och Mac utan DHCP är bara för underhåll och ger inte internet till Pi eller gästerna.
  • Återkallelse vid evenemangets slut är den primära rensningen. Sjudagars utgång är bara en reservåtgärd och förutsätter att Pi-klockan fungerar.

Om något inte fungerar

Stationen är fel eller matchar inte
Överför inga foton. Ägaren måste kontrollera och reparera stationens parkoppling. Starta sedan ett nytt evenemang; samma evenemangs-ID löser inte felet.
Stationen visar fortfarande ”Kontrollerar” eller ingen foto-QR visas
Pi måste vara nåbar och bekräfta fotot innan en QR-kod visas. Kontrollera att iPad och Pi använder det avsedda lokala nätverket; kontakta ägaren om väntan fortsätter.
iPad når inte Pi på det lokala nätverket
Tillåt appen att använda det lokala nätverket och anslut iPad till Pi-Wi-Fi. Internet behövs inte.
Kopior finns kvar på Pi efter evenemanget
Lås upp operatörsdelen och anslut Pi igen. Appen måste bekräfta den väntande borttagningen. Kopior som redan sparats på telefoner kan inte tas bort.
